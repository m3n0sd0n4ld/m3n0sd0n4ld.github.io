Go CVE

uCVE

Herramienta escrita en Go que permite extraer CVE's relacionados con un determinado software y versión, obteniendo un informe en HTML y/o exportándolo al informe de pentesting.

Ver en GitHub
Bash OSINT Google Dorking

GooFuzz

Fuzzing con enfoque OSINT: enumera directorios, archivos, subdominios o parámetros sin dejar evidencias en el servidor del objetivo mediante búsquedas avanzadas en Google (Google Dorking).

Ver en GitHub
Bash OSINT Descontinuada

uDork

Script en Bash que usa técnicas avanzadas de búsqueda en Google para obtener información sensible en archivos o directorios, encontrar dispositivos IoT o detectar versiones de aplicaciones web. (Descontinuada)

Ver en GitHub
Python Fuerza bruta

uNominaCracker

Script en Python que realiza fuerza bruta sobre los ficheros ZIP con nóminas de trabajadores mediante el uso del DNI (Documento Nacional de Identidad).
